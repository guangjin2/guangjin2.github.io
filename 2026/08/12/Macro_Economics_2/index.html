国民收入决定理论

1.凯恩斯定律和萨伊定律

  • 凯恩斯定律

    • 需求决定供给和均衡产出，一个经济社会的总产出是由需求决定的。
    • 条件： 生产力较高，生产资料足够
    • 看的见的手： 市场需要靠政府制定看得见的明确规则来调整。

  • 萨伊定律

    • 供给会创造自己的需求(供给决定需求)
    • 条件：生产力不能太高，物资匮乏
    • 看不见的手:市场靠看不见的潜规则自我调整

2.均衡产出

  • 需求决定供给， 企业的任务是配合需求确定产量， 没有能力改变价格
    • 均衡时:1.总供给=总需求=总产出2.短期内物价水平有粘性
    • 区别于第一章，总产出不一定等于总支出(核算时相等，但经济发生中不一定总相等)
    • 计划投资i=计划投资s
      • 总支出(总需求)E=消费+投资=c+i
      • 总收入(总供给)y=消费+储蓄=c+s

3.消费

  • 影响因素： 收入、价格、利率、贫富差距、偏好、家庭财产、信用等级、年龄、风俗、社会保障等
    • 其中以收入影响最为重要
      • 消费函数y = f(x)
      • 边际消费倾向（MPC, Marginal Propensity to Consume）= 消费变化量/收入变化量 = Δc/Δy,通常是递减的
      • 平均消费倾向（APC, Average Propensity to Consume）= 消费/收入 = c/y, 通常是递减的
        消费函数 MPC APC
      • 边际储蓄倾向(MPS,Marginal Propensity to Save): MPC[边际消费倾向]+MPS[边际储蓄倾向]=1, 通常是递增的
      • 平均储蓄倾向(APS,Average Propensity to Save): APC[平均消费倾向]+APS[平均储蓄倾向]=1, 通常是递增的

4. 消费函数和储蓄函数

  • 消费函数: c = α+βy
    • α:自主消费，维持正常生活的最低消费
    • β:边际消费倾向(MPC)
    • βy:引致消费
    • APC = c/y = (α+βy)/y = α/y+β
  • 储蓄函数: s = y-c = y-(α+βy) = -α+(1-β)y
  • 均衡产出公式（二部门）
    • y = c+i = α+βy+i => y=(α+i)/(1-β)
    • y = c+s = c+i = c-α+(1-β)y => y=(α+i)/(1-β)
    • 应用:α、β 易统计且短期不怎么变化，假设知道计划投资i,则可以算出均衡产出y和消费c，可知均衡产出主要随投资i变化而变化

5. 投资乘数

小写字母代表经济变量的实际值, 剔除了价格影响之后的真实价值。
大写字母表示经济变量的名义值。

  • 投资乘数： 产生的变化是引起产生这种变化的投资的多少倍数
    • 投资:花钱买新的生产资料，或者购买新的生产要素
    • 投资乘数=1/(1-MPC) = 1/(1-β)= 1/MPS
      定义 传递形成等比数列

6.多部门均衡与各种乘数

  • 三部门均衡产出

    • y = c+i+g
    • c = α+β(y-t), t为税收，y-t即可支配收入
    • 由上两式可得y=(α+i+g-β)/(1-β)

  • 政府购买乘数： 产生得变化是引起产生这种变化的政府购买变化的多少倍数

    • $k_g = \frac{\Delta y}{\Delta g} \quad$ = 1/(1-β)
      • 注意区别投资乘数，这里的β是扣除可支配收入后的消费边际倾向

  • 税收乘数:均衡产出的变化量是引起均衡产出这种变化的政府税收变化量的多少倍

    • $k_t = \frac{\Delta y}{\Delta t} \quad$ = -β/（1-β）

  • 转移支付乘数:均衡产出的变化量是引起均衡产出这种变化的政府转移支付变化量的多少倍

    • $ k_{t_r} = \frac{\Delta y}{\Delta t_r} \quad $ = β/(1-β)

  • 平衡预算乘数:政府购买(支)和税收(收)增加同样数量，也就是政府预算平衡时，总产出多出来那部分与政府收、支变化量的比率。

    • $ \Delta y_{\text{(多余)}} = k_g \Delta g + k_t \Delta t $
    • 只考虑税收是定量税的情况下，总是等于1

助记： 跟家庭消费相关的乘数分子均与β相关

政府购买乘数 税收乘数 转移支付乘数

7.节俭悖论

  • 节俭悖论:家庭勤俭节约，会让国家变穷;而国家要富，家庭就得挥霍无度，败家
    • 凯恩斯定律更适合低迷的经济，经济越热，凯恩斯定律(刺激需求)，效果越差。

8.外贸乘数

  • 四部门总产出y = c+i+g+nx, nx=x(出口)-m(进口)
    • 外生变量:一种变量，能影响系统中其他变量，而本身却不受系统以及其他变量影响。
      • 出口是外生变量， 进口是内生变量
    • $m = m_0 + \gamma y$， 只考虑进口受收入影响时
      • $m_0$: 自发性进口
      • $\gamma$： 边际进口倾向
    • $y=(\alpha+\beta(y-t+t_r))+i+g+x-(m_0+\gamma y)$
      • 整理得： $ y = \frac{\alpha + i + g - \beta t + \beta t_r + x - m_0}{1 - \beta + \gamma} $
      • 求乘数即是对相关项的求偏导
        • 外贸乘数： $ \frac{dy}{dx} = \frac{1}{1 - \beta + \gamma} $
